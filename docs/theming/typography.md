# 토스뱅크 타이포그래피 시스템 (Typography System)

토스뱅크의 명료하고 군더더기 없는 커뮤니케이션을 완성하는 타이포그래피 시스템입니다. 가변 폰트 `Pretendard Variable`과 한글에 최적화된 밀착 자간(`-0.02em`)을 적용하여 금융 숫자의 가독성과 텍스트의 판별력을 극대화합니다.
