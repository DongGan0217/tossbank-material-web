# 토스뱅크 형태 시스템 (Shape System)

토스뱅크의 직관적이고 친근한 감성을 대변하는 스쿼클 코너 래디우스(Corner Radius) 시스템입니다. 기본 버튼/인풋의 16px 곡률부터 통장/카드 컴포넌트의 20px, 모달의 24px, 캡슐형 Pill의 9999px에 이르기까지 일관된 곡률 계층을 제공합니다.
