# 카카오뱅크 디자인 시스템 (KakaoBank Material Web)

**`@kakaobank/material-web`**은 대한민국 1위 인터넷 전문은행 카카오뱅크의 디자인 아이덴티티와 Google Material Design 3의 Web Components 표준 기술을 소스 레벨에서 통합한 독자적인 엔터프라이즈 디자인 시스템입니다.

---

## 1. 핵심 철학 (Design Philosophy)

- **친근하고 신뢰할 수 있는 금융**: 시그니처 카카오 옐로우(`#FFE100`)와 명확한 흑백 대비를 통해 사용자에게 따뜻하면서도 정확한 금융 정보를 제공합니다.
- **모바일 최적화 사용자 경험**: 터치 오류를 방지하는 넉넉한 52px 높이와 안정적인 16px 둥근 모서리를 표준 규격으로 채택했습니다.
- **W3C 표준 Web Components**: 특정 프레임워크(React, Vue, Angular)에 종속되지 않고 어떤 웹 환경에서나 자유롭게 동작합니다.
- **Pretendard Variable 웹폰트**: 한국어 조형미와 금융 수치 표현에 가장 최적화된 서체와 밀착 자간(`-0.03em`)을 기본 내장합니다.

---

## 2. 패키지 구성

- **Core Components**: 버튼, 입력 폼, 다이얼로그, 바텀시트, 탭스 등 18개 핵심 컴포넌트
- **Icons Library**: 카카오뱅크 웹 및 모바일 앱에서 추출된 140+종의 공식 SVG & WebP 아이콘
- **Design Tokens**: DTCG 표준 3-Tier CSS 커스텀 속성 기반 토큰 시스템
