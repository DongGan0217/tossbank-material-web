# 브라우저 지원 및 웹 접근성 (Browser Support & A11y)

카카오뱅크 서비스의 모든 고객이 차별 없이 이용할 수 있도록 광범위한 브라우저 지원과 웹 접근성 표준을 준수합니다.

---

## 1. 브라우저 지원 범위

- **Mobile**: iOS Safari 14+, Android Chrome / WebView 88+, Samsung Internet 14+
- **Desktop**: Chrome 88+, Safari 14+, Edge 88+, Firefox 85+

---

## 2. 웹 접근성(A11y) 가이드

- **명도 대비(Contrast Ratio)**: 카카오 옐로우(`#FFE100`) 배경 위의 텍스트는 순수 블랙(`#000000`)으로 고정하여 14:1 이상의 최고 수준 가독성을 보장합니다.
- **키보드 탐색 및 스크린 리더**: 모든 컴포넌트는 WAI-ARIA 규격을 충족하여 키보드 탭 탐색 및 음성 보조 기능을 완벽 지원합니다.
