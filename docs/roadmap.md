# 토스뱅크 디자인 시스템 로드맵 (Roadmap)

토스뱅크 엔터프라이즈 디자인 시스템(`@tossbank/material-web`)의 지속적인 진화 계획입니다.

---

## 1. 버전별 개발 로드맵

- **v1.0.0 (현재 릴리즈)**:
  - Google 공식 Material Web 원본 소스 풀 하드포크 및 `@tossbank/material-web` 독립 패키지화
  - 토스뱅크 딥 로얄 블루(`#0064FF`), 16px 스쿼클 코너, 듀얼톤 체크카드 포인트 팔레트 소스 레벨 완전 이식
  - 18종 전수 컴포넌트 리팩토링 및 18종 전수 실시간 옵션 플레이그라운드 샌드박스 완비
  - 20종 토스뱅크 전용 벡터 SVG 히어로 배너 (400x160) 자체 제작
  - 4대 실전 Showcase (공식 웹, iPhone 16 Pro 모바일 앱, 백오피스 어드민, PMS) 사이드바 최하단 신설
  - 140+종 공식 아이콘 7대 도메인 탭 갤러리 및 880개 이미지 AI 시맨틱 분류 메타데이터 탑재
  - 멀티 테넌트 디자인 시스템 통합 Hub (`design-system-hub.html`) 및 상단바 상호 전환 스위처 연동

- **v1.1.0 (예정)**:
  - React 19 전용 화이트박스 레지스트리 패키지(`@tossbank/react-ui`) 100% 오픈 배포
  - 토스뱅크 비대면 신분증 촬영 가이드 및 보안 모바일 OTP 전용 커스텀 컴포넌트 추가
  - 통장/적금 금리 실시간 시뮬레이션 인터랙티브 차트 위젯 도입

- **v1.2.0 (예정)**:
  - Figma Token Studio 양방향 실시간 싱크 파이프라인 연동
  - LLM 자연어 기반 원클릭 토스뱅크 금융 UI 코드 자동 생성 플러그인 탑재
