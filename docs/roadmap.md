# 카카오뱅크 디자인 시스템 로드맵 (Roadmap)

카카오뱅크 디자인 시스템의 지속적인 진화 계획입니다.

- **v1.0.0 (현재)**:
  - Google Material Web & Android 원본 소스 풀 하드포크 및 독립화
  - 카카오 옐로우(`#FFE100`), Pretendard Variable 웹폰트, 52px 높이, 16px 라운드 전면 내장
  - 140+종 공식 아이콘 및 이미지 라이브러리 연동
  - Android Material 3 디버그 APK (`Theme.Material3.KakaoBank`) 빌드 완결
- **v1.1.0 (예정)**:
  - React/Vue 전용 래퍼 컴포넌트 라이브러리(`@kakaobank/material-react`) 출시
  - 모바일 웹뷰 금융 입력 보안 핀패드 및 계좌 카드 특화 컴포넌트 추가
- **v1.2.0 (예정)**:
  - Figma 디자인 토큰 양방향 싱크 플러그인 연동
