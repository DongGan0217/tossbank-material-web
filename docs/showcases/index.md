# 토스뱅크 4대 실전 Showcase (Real-World Showcases)

`@tossbank/material-web` 리팩토링된 엔터프라이즈 컴포넌트를 100% 사용하여 조립한 **4대 실전 비즈니스 쇼케이스**입니다. 토스뱅크의 대표 대고객 웹 서비스부터 모바일 뱅킹 앱, 백오피스 여수신 심사 어드민, 신상품 프로젝트 관리 시스템(PMS)에 이르기까지 실무 핀테크 환경의 다양한 유저 저니와 인터랙션을 직접 체험할 수 있습니다.
