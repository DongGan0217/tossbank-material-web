Design Principles & Core Values

💛 Signature Kakao Yellow

브랜드 시그니처 컬러(#FFE100)와 순수 블랙(#000000) 텍스트를 기본 시스템 토큰으로 내장하여 완벽한 금융 가독성과 브랜드 아이덴티티를 확립합니다.

🔤 Pretendard Variable Typography

국내 최적화 산세리프 Pretendard Variable 웹폰트와 -0.03em의 정밀 자간 설계를 W3C DTCG 3-Tier 토큰으로 전면 주입하였습니다.

📱 52px Touch Targets & 16px Corners

금융 앱 사용자 경험에 최적화된 52px 넉넉한 터치 영역과 16px 둥근 모서리 코너 래디우스를 모든 컴포넌트에 표준화하였습니다.

🌐 100% W3C Web Components

React, Vue, Angular 등 모든 프레임워크와 프레임워크-프리(Vanilla JS) 환경에서 완벽하게 상호운용되는 표준 웹 컴포넌트입니다.

Component Categories
