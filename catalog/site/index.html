Design Principles & Core Values

🔵

Signature Toss Blue

토스뱅크 고유의 딥 로얄 블루(#0064FF)와 서브 톤(#3182F6, #E8F3FF)을 W3C DTCG 3-Tier 시스템 토큰으로 내장하여 신뢰성과 직관성을 극대화합니다.

🔲

16px Continuous Squircle

극도로 부드러운 토스뱅크 시그니처 16px 스쿼클 곡률 시스템과 52px 터치 타겟을 18개 전 컴포넌트에 표준화하여 모바일 및 웹 사용성을 보장합니다.

🔤

Pretendard Typography

한국어 가독성에 최적화된 Pretendard 웹폰트와 정밀 자간(-0.03em), 1.6 배수 줄간격을 적용하여 금융 텍스트 가독성을 최상위로 끌어올렸습니다.

⚡

100% W3C Web Components

Lit 기반의 Shadow DOM과 SSR Hydration을 완벽 지원하며, React, Vue, Angular, Vanilla JS 환경 어디서든 프레임워크 제약 없이 작동합니다.
